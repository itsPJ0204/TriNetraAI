Feasibility
Decoupled Modularity: 5 independent functional blocks eliminate merge bottlenecks.

Challenges
Illumination & Sun Angle: Varying sun azimuth creates false pixel brightness differences.
Heavy Tropical Cloud Cover: Monsoon cloud occlusions hide ground terrain.
Gigabyte Scene Memory Limits: Large GeoTIFFs cause RAM overflow during processing.
Air-Gapped Operation: Defense units cannot call external cloud LLM APIs.
🎯
Strategies
Spatial Attention (BIT): Transformer attends to structural shapes, ignoring illumination shifts.
SCL + Halo Erosion: Multi-band scene classification strips clouds before detection.
Windowed Raster Streaming: Chunked 512x512 geographic grid tiling maintains low RAM usage.
Local Embedded Vector DB: In-memory Qdrant & local RemoteCLIP weights.
